# Instruções para Claude Code — Cozinha SaaS

Antes de alterar qualquer arquivo, leia `AGENTS.md`, `docs/COORDENACAO_IA.md` e `docs/IA_ESTADO.md`. Siga o protocolo de coordenação, os gates de qualidade e as regras de domínio de `AGENTS.md`; eles se aplicam a todos os assistentes que trabalham neste repositório. Respeite instruções específicas mais recentes do usuário.

Registre o andamento em checkpoints durante a execução, inclusive testes que falharam, trabalho incompleto e próximo passo. Não presuma que outra conversa, máquina, worktree ou branch já recebeu suas alterações: confira o Git e o remoto. Nunca inclua credenciais, dados pessoais ou informações sensíveis no registro.
